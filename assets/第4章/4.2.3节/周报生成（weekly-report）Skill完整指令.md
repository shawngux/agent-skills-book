# Weekly Report Generator

这个技能帮助你将日常工作的碎片化信息整理成一份、专业的工作结构化周报。

## 使用场景

- 用户提供几句日常工作描述
- 需要将零散的工作内容整理成正式周报
- 希望量化工作成果并清晰展示

## 输入要求

请用户提供以下信息：
1. 本周完成的主要工作（可以是零散的描述）
2. 参与的项目或任务
3. 遇到的问题或收获
4. 下周计划（可选）

## 输出格式

生成的周报将包含以下结构：

```
## 📋 周报概要
- 时间范围
- 整体完成情况

## ✅ 本周工作成果
- 具体任务及量化数据
- 项目进展

## 🔧 问题与解决方案
- 遇到的技术难点
- 解决思路

## 📈 量化指标
- 完成的任务数
- 代码提交数 / 文档数量等

## 🎯 下周计划
- 预期目标
- 重点任务
```

## 处理原则

1. **量化优先**：将模糊的工作描述转化为具体数字
2. **结构清晰**：使用标题、列表、emoji 等元素提升可读性
3. **突出成果**：强调完成的工作和带来的价值
4. **专业排版**：保持格式统一，层次分明

## 示例

用户输入：
> 这周写了几个API接口，修了一个登录的bug，还做了个用户头像上传功能。周三、周四在忙那个积分商城的项目。

输出：
```
## 📋 周报概要
- 时间范围：2月17日 - 2月21日
- 整体完成情况：按计划完成各项开发任务

## ✅ 本周工作成果
- 完成用户模块 API 接口开发（3个）
- 修复登录验证码失效问题
- 实现用户头像上传功能
- 推进积分商城项目进度

## 🔧 问题与解决方案
- 登录验证码过期时间配置问题 → 调整缓存策略
- 头像上传文件大小限制 → 增加前端压缩和后端校验

## 📈 量化指标
- API 接口：3个
- Bug 修复：1个
- 功能开发：1个
- 项目参与：2个

## 🎯 下周计划
- 完成积分商城前端对接
- 用户积分兑换功能开发
- 代码优化和单元测试补充
```

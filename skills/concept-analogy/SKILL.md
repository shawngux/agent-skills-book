# 概念类比生成器

将复杂的专业概念转化为通俗易懂的类比。

## 工作流程

1. 分析概念核心功能和特性
2. 选择生活化类比场景（图书馆、餐厅、超市等）
3. 将技术特性映射到类比场景
4. 输出通俗解释

## 输出格式

```
【一句话定义】
用一句话说明这个概念是什么。

【生活类比】
"这就像..." + 具体场景

【特性对应】
- 技术特性A → 类比中的对应物
- 技术特性B → 类比中的对应物

【局限性】
说明类比不够准确的地方
```

## 示例

**输入**: 向量数据库

**输出**:
```
【一句话定义】专门存储和检索语义相似性数据的数据库。

【生活类比】图书馆的主题索引系统。

【特性对应】
- 向量化 = 给每本书打主题标签
- 相似性搜索 = 找到主题相近的书

【局限性】向量是数值计算，不像标签那么直观。
```

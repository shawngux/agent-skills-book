# 智谱小龙虾AutoClaw，对小白友好的本地客户端OpenClaw

OpenClaw 爆火的同时，国内不少友好版也陆续跟进推出。

体验了一圈之后，发现在功能相对丰富性和部署使用门槛低两个方面做的不错的，我觉得智谱的 AutoClaw 算是一个。

加上刚刚不久智谱推出的专门为 OpenClaw 深度优化的「龙虾模型」GLM-5-Turbo，让 AutoClaw 在复杂任务中，表现更加不俗。

![Screenshot](images/04/01.png)

在智谱官方的文档中介绍到，GLM-5-Turbo 在训练阶段就针对 OpenClaw 任务进行专项训练，对工具调用、指令遵循、定时与持续性任务、长链路执行等核心能力做了强化。

![Screenshot](images/04/02.png)

在我看来，从功能和使用门槛上来看，AutoClaw 或许是当下对小白用户最友好的本地可安装版的「小龙虾」了。

![Screenshot](images/04/03.png)

AutoClaw 支持 Mac 和 Windows 版本。
官网链接：https://autoglm.zhipuai.cn/autoclaw/ 。
进入官网后，你可以点击「下载体验」按钮，自动下载对应系统的安装包，然后安装一下。

![Screenshot](images/04/04.png)

之后，打开 AutoClaw，需要使用手机号登录一下。

![Screenshot](images/04/05.png)

登录之后，进入交互首页，你会看到默认已经给你创建好了几个小助手。

![Screenshot](images/04/06.png)

如果是首次安装使用，打开后可能有权限设置相关的提示步骤，根据指示往下走就好。

点开任意一个助手，其实已经可以直接用了。

默认内置的模型就是智谱专门为 OpenClaw 深度训练的「龙虾模型」GLM-5-Turbo。

![Screenshot](images/04/07.png)

AutoClaw 还有一个比较好用的功能是深度集成自家的 Browser Use 能力，也就是操作浏览器功能。

有了操作浏览器这个功能，可干的事情就多了。

比如就拿 AutoClaw 自行给我们创建的 Browser Agent 助理，来搜索小红书热门笔记试试。

![Screenshot](images/04/08.png)

根据执行提示，做适当配置，确保 Browser Use 能力开启。

![Screenshot](images/04/09.png)

然后它就自行打开浏览器去干活了。

![Screenshot](images/04/10.png)

任务复杂，过程可能耗时比较久，而且消耗的积分挺快的。

当下，更多是接入到飞书中使用。

在 AutoClaw 中接入飞书，也非常简单。

点击左侧导航处的「IM 频道」标签，进入配置页。

![Screenshot](images/04/11.png)

目前是支持「飞书」和「企业微信」，估计其他渠道也会很快接入。

接入飞书有两种方式，一种是点击「添加频道」按钮，弹出频道选择框，选择「飞书选项」。

![Screenshot](images/04/12.png)

这个时候，会弹出 App ID 和 App Secret 配置框。

这种方式适合对飞书机器人配置熟悉的小伙伴，可以去飞书开发平台创建机器人，然后把 App ID 和 App Secret 复制过来进行配置。

![Screenshot](images/04/13.png)

更简单的方式是单击快速添加这里的「飞书」按钮，自动配置接入。

![Screenshot](images/04/14.png)

在「接入飞书机器人」这个对话框里，点击「开始自动配置」按钮。

![Screenshot](images/04/15.png)

弹出飞书登录页，扫个码就好。

![Screenshot](images/04/16.png)

然后全自动完成创建和配置等等，所有的切换页面步骤，全程自动化，你就看着就好。

全程打开几十秒钟，就配置好了。

![Screenshot](images/04/17.png)

在飞书消息里，点击消息卡片中的「打开应用」按钮，进入对话窗口。

![Screenshot](images/04/18.png)

在飞书对话窗口中，一切就都变得这么熟悉了。

![Screenshot](images/04/19.png)

AutoClaw 默认给我们提供了不少好用的Skills。

![Screenshot](images/04/20.png)

自家的几个技能包括操作浏览器、深度研究、数据分析等，要比起其他第三方的好用很多。

![Screenshot](images/04/21.png)

除了使用默认提供的「龙虾模型」GLM-5-Turbo，AutoClaw 也提供了自定义模型的入口。

![Screenshot](images/04/22.png)

这对于想要使用其他厂商模型的用户，就很方便了。

![Screenshot](images/04/23.png)

在「工作区」页，你可以看到默认的工作目录，以及几个配置选项。

![Screenshot](images/04/24.png)

尤其是「限制文件访问范围」项，这个打开，AutoClaw 操作的空间就很大了，不过风险也加大了，所以是否开启要慎重。

AutoClaw 完全兼容 OpenClaw，所以如果你本地部署过 OpenClaw，可以完全迁移过来，使用 AutoClaw 可视化管理。

AutoClaw 对于想要在本地体验小龙虾的普通用户来说，值得试试。

不过，工具是免费的，但是消耗的 Token 是需要实打实付费的。

所以，如果仅仅是体验玩玩，建议考虑接入相对便宜的套餐，真正想要深度使用并提高生产力的， 这个 Token 费用，还真是不得不投入的。
